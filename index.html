Quem sou eu

Sou estudante de Engenharia de Software na Universidade Positivo e Aprendiz na Koube Química do Brasil, onde aplico tecnologia no dia a dia de uma fábrica. Meu trabalho começa ouvindo quem está na operação: entender onde o processo trava, onde as informações se perdem e onde o retrabalho consome tempo. A partir disso, construo ferramentas simples que organizam os dados e dão mais autonomia para quem toma decisões.

“Transformo processos manuais em software que funciona no dia a dia.”

Plano de carreira

Desenvolvimento de software, começando por back end e dados e ampliando para outras áreas ao longo da carreira, sempre criando sistemas que resolvem problemas reais de operação.

Ponto forte

Resolução de problemas reais. A automação com Python e a integração de dados operacionais (TOTVS, relatórios do Envase) mostram que entendo as regras do negócio, não só o código.

Base atual

Python (scripts e back end), banco de dados (PostgreSQL/SQL), front end básico (HTML, CSS e JavaScript) e noções de Docker para implantação.

A desenvolver

Consolidar Java para back end corporativo, aprofundar JavaScript para atuar como Full Stack e evoluir no inglês.

Metas SMART

  1. Foco: Python ou Java (Spring Boot) e SQL avançado

    • Candidatar-me a vagas de estágio em back end, usando os repositórios atuais como portfólio.
    • Iniciar um cronograma fixo de estudo de inglês, com foco em leitura técnica e escuta.
    • Adicionar testes automatizados ao Sistema de Gestão de Produção e Manutenção.

  2. Foco: APIs REST, arquitetura e JavaScript/React

    • Definir a trilha: aprofundar o back end ou adicionar um framework front end para atuar como Full Stack.
    • Passar de projetos individuais para contribuições em equipe (open source ou projetos da faculdade).
    • Praticar conversação em inglês (B1/B2) para entrevistas.

  3. Foco: microsserviços, mensageria, cloud e System Design

    • Participar de projetos de diferentes áreas (indústria, finanças, logística) para ampliar a visão de negócio.
    • Liderar integrações e resolver gargalos de performance.
    • Alcançar inglês fluente (C1) e obter certificações em arquitetura ou cloud.

  4. Concluir a graduação e consolidar a carreira

    • Consolidar-me no mercado, com experiência em várias áreas da tecnologia: back end, dados, front end e infraestrutura.
    • Chegar ao nível de especialista e participar de decisões de arquitetura.
    • Empreender na área de tecnologia, criando soluções próprias para empresas, principalmente da indústria.
